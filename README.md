# CIS 321 Final Project
Demand Forecast System
1.	Download the repository
2.	Make sure to have virtual environment create and active.
3.	Download the pandas, numpy, scikit-learn, and joblib libraries.
4.	Run create_database.py and then run import_data.py to create the database. 
5.	Run train_model.py.
6.	Run generate_forecast.py, which will post an output in the terminal.
